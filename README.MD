# Oficina Bom Motor

🔧 Branch atual: secao-orcamentos — em desenvolvimento, adicionando a seção de orçamentos à página inicial.

Landing page da Oficina Bom Motor, com informações sobre os serviços oferecidos, diferenciais da oficina e formulário de agendamento online.

## Tecnologias

HTML e CSS.

## Estrutura de arquivos

- `index.html`: página inicial com apresentação da oficina, serviços, diferenciais e avaliações
- `estilo.css`: estilos gerais do projeto
- `agendamento.html`: página com o formulário de agendamento de serviços
- `agendamento.css`: estilos específicos da página de agendamento
- `assets/`: imagens utilizadas no projeto

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador.

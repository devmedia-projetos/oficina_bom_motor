# Oficina Bom Motor

Landing page de uma oficina mecânica que apresenta os serviços oferecidos, informações de localização, horário de funcionamento e um botão de contato via WhatsApp.

## Tecnologias utilizadas

- HTML5
- CSS3

## Estrutura de arquivos

oficina/
├── index.html        Página principal
├── estilo.css        Estilos da página
└── assets/
    └── banner_oficina.png  Imagem de destaque da página

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador.

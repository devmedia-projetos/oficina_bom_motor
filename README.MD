# Oficina Bom Motor

Landing page de uma oficina mecânica com apresentação de serviços, informações de contato e página de agendamento online.

## Sobre o projeto

O site da Oficina Bom Motor foi desenvolvido para apresentar os serviços da oficina, facilitar o contato com clientes e permitir o agendamento de serviços diretamente pelo navegador, sem necessidade de ligação ou deslocamento.

## Páginas

| Página | Descrição |
|---|---|
| `index.html` | Landing page principal com serviços, avaliações e informações de contato |
| `agendamento.html` | Formulário de agendamento de serviços com confirmação em até 2 horas |

## Serviços disponíveis

- Troca de óleo
- Revisão completa
- Alinhamento e balanceamento
- Suspensão
- Freios
- Elétrica

## Tecnologias utilizadas

- HTML5
- CSS3

## Estrutura de arquivos

```
oficina/
├── index.html           # Página principal
├── estilo.css           # Estilos da página principal
├── agendamento.html     # Página de agendamento de serviços
├── agendamento.css      # Estilos da página de agendamento
└── assets/
    └── banner_oficina.png  # Imagem de destaque da página
```

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador. Para acessar a página de agendamento, clique no link "Agendar serviço" disponível no menu e no banner da página principal.
